A Python program (standard library only) that draws one cute picture — a chubby baby panda hugging a bamboo stalk, with a tiny red scarf — and writes it to entry.png as a hand-encoded PNG. Deterministic: every run produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
